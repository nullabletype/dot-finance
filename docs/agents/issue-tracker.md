# Issue tracker

Use GitHub Issues in `nullabletype/dot-finance` and Project 2 owned by `nullabletype`: https://github.com/users/nullabletype/projects/2.

Use `gh` for ticket operations. Issues are the authoritative queue. Link PRs and record tested commits and evidence. Create native blocked-by edges where supported; also state dependencies in issue bodies. External PRs are not treated as incoming feature requests in this project.

Use the board's existing statuses: Todo, In Progress, Done. Triage labels distinguish readiness and review within those states. Move to Done only when acceptance gates are satisfied and implementation is integrated, or an experiment's evidence and decision are accepted. Do not automatically close experiment issues with outstanding owner reviews.
