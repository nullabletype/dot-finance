# Triage labels

| Role | Label | Meaning |
| --- | --- | --- |
| Needs triage | needs-triage | Needs evaluation or a scope decision |
| Needs information | needs-info | Missing information prevents progress |
| Ready for agent | ready-for-agent | Specified and dependencies complete |
| Ready for human | ready-for-human | Owner decision or acceptance required |
| Will not action | wontfix | Deliberately not proceeding |

Additional labels: `prototype` for bounded experiments, `blocked` for unfinished dependencies or environmental blockers, and `in-review` for completed work awaiting review. Do not apply `ready-for-agent` while blockers remain. Promotion is manual until the controller is implemented and verified.
