`build/DesktopDependencies.props` supplies the explicit managed/native graphics and DBus pins to the production shell and the disposable desktop probes. This intentionally overrides Avalonia's older minimum dependencies to meet the repository support policy. It does not assume upstream Avalonia has completed its SkiaSharp 4 upgrade: compatibility must be validated with the actual native workflows on all supported targets. No warning suppression, full-assembly trimming roots or runtime-version forcing is used.

The prototype regression suite also retains Microsoft.Data.Sqlite.Core 10.0.12, CsvHelper 33.1.0 and SQLite3MC.PCLRaw 2.4.0 (current wrapper package), and advances SQLitePCLRaw.core to 3.0.5. In particular, 3.0.3 fixed memory-corruption bugs. SQLite3MC source 2.5.0 changes symbol visibility/dispatch-table options and 2.5.1 fixes WebAssembly; the retained desktop shared-library route uses one SQLite instance and does not use those changed paths. The package/source distinction and future production cipher/persistence review remain explicit under #29. [SQLitePCLRaw releases](https://github.com/ericsink/SQLitePCL.raw/releases), [SQLite3MC wrapper](https://www.nuget.org/packages/SQLite3MC.PCLRaw.bundle/2.4.0), [native changes](https://github.com/utelle/SQLite3MultipleCiphers/releases).

Local NuGet checks of the updated production graph reported no published vulnerabilities or deprecations; npm audit reported zero vulnerabilities. These catalogue checks supplement the support review and are not proof that every vulnerability is known. Re-run them when pins change. Exact-commit validation evidence belongs on the issue/PR; local dirty-tree checks remain provisional.
